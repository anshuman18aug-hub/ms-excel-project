# Sales Performance Dashboard – Excel

## Overview

An interactive sales performance dashboard developed in Excel to analyze sales data and track key sales metrics.

## Business Problem

Analyze sales performance to understand regional and category-level trends and provide a clear view of important sales KPIs.

## Tools & Technologies

- Microsoft Excel
- Power Query
- Pivot Tables
- Slicers
- Excel Charts
- Conditional Formatting
- Data Visualization

## Data Preparation

Used Power Query to:

- Remove duplicate records
- Handle null values
- Standardize raw sales data
- Prepare the dataset for analysis

## Dashboard Features

- Interactive sales performance dashboard
- KPI tracking
- Pivot Tables
- Slicers and Filters
- Sales charts
- Conditional Formatting

## Analysis

The dashboard enables dynamic analysis of sales performance across regions and categories using Pivot Tables, Slicers, and Filters.

## Key Insight

The dashboard was designed to make sales reporting faster and more efficient by providing interactive analysis of key sales metrics.
